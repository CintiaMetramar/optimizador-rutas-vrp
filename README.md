# 🚛 Optimizador VRP de Rutas - Gestión de Residuos

Sistema inteligente de optimización de rutas VRP para gestión de recolección de residuos.

## 🚀 Características Principales

- **Algoritmo VRP Avanzado**: Optimización con Time Windows, Capacities, Pickup & Delivery
- **Geocodificación Automática**: Usa OpenStreetMap (gratuito)
- **WhatsApp Web Integration**: Envío automático a conductores
- **Gestión de Conductores**: Base de datos integrada
- **Exportación Multiple**: Excel, KML, informes PDF
- **Interfaz Streamlit**: Moderna y fácil de usar

## 📋 Requisitos Previos

- Python 3.8 o superior
- Cuenta GitHub
- Navegador web moderno
